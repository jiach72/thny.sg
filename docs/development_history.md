# 项目开发里程碑日志

本日志记录了 `tonghai-nanyang` 项目的关键开发节点和演进过程。

## 2026-01-30：里程碑级版本交付 (v1.1)

本日完成了全项目的综合审计与大规模功能迭代，涉及前端、后端、文档及架构的全面升级。

### 1. 核心功能模块交付
*   **[F] 官网聊天机器人 (AI Chatbot)**: 全栈交付。集成 OpenAI，实现官网悬浮窗、后台知识库管理 (FAQ/Categories) 及会话记录统计。
*   **[F] 新闻资讯板块 (News Module)**: 全栈交付。实现 RSS 自动聚合 + 微信公众号素材同步，包含官网展示与后台内容管理系统。
*   **[F] AI 配置中心**: 新增系统设置模块，支持 AI 参数动态配置与热加载。
*   **[F] 负责人分配**: 实现线索 (Lead) 的负责人分配功能，打通了 User API 与业务流的关联。

### 2. 紧急修复与稳定性 (Critical Fixes)
*   **[B] 后端测试修复**: 修复 `authService.test.ts` 中 `prismaMock` 的循环引用与 TS 类型错误。
*   **[F] 前端警告清除**: 修复 `Contact.vue` 和 `ReportCenter.vue` 中 Element Plus `el-checkbox/radio` 的 `label` 弃用警告，修复 `apiClient` 类型定义。
*   **[B] 文件服务重构**: 修复 DocumentService，实现项目文件上传/下载及鉴权逻辑。
*   **[F] 客户门户修复**: 修复 `admin@thny.sg` 登录问题，解决 ProjectDetail 页面崩溃及关联查询错误。
*   **[F] 交互修复**: 修复联系顾问 Dialog，修正消息通知 (Unread Count) 逻辑。
*   **[S] 类型系统**: 重构 i18n 类型定义，修复 130+ TS 构建错误，确保 CI/CD 畅通。

### 3. 架构重构与优化 (Refactoring)
*   **[R] Dashboard 拆分**: 将 800+ 行的 Dashboard.vue 拆解为 7 个独立原子组件，提升可维护性。
*   **[S] API 标准化**: 建立 `ApiResponse<T>` 统一响应规范，完成 Auth/News 模块迁移及前端智能拦截器适配。
*   **[R] 代码规范**: 统一 Monorepo 的 ESLint (v8) + Prettier 配置，清理大量死代码与未使用变量。

### 4. 规划与文档
*   **[D] 深度审计**: 完成全项目技术审计，输出《项目升级与完善蓝图 v2.0》。
*   **[P] 功能规划**: 明确了 v2.0 路线图，涵盖线索评分、工作流自动化等未来方向。
