## 如何添加新决策

请复制以下模板创建新的 `.md` 文件，文件名格式建议为 `NNNN-title-in-kebab-case.md`。

---

### [ADR 模板]

# 标题

**状态**: [提议 / 已采纳 / 已弃用 / 已取代]
**日期**: YYYY-MM-DD
**作者**: [Name]

## 背景 (Context)

[描述面临的问题、背景信息以及为什么需要做出这个决策。]

## 选项 (Options)

1.  **选项 A**
    *   利: ...
    *   弊: ...
2.  **选项 B**
    *   利: ...
    *   弊: ...

## 决策 (Decision)

我们要选择 **[选项]**，因为 [原因]。

## 后果 (Consequences)

*   [+] 带来的好处。
*   [-] 产生的负面影响或需要注意的代价。
*   [!] 需要采取的后续行动。
