## 关键决策记录

| 决策 | 理由 |
|------|------|
| 密码重置复用 `setupToken` 字段 | 避免 schema migration，字段语义一致 |
| CSV 导出而非 Excel | 无需第三方 xlsx 库，BOM UTF-8 确保中文兼容 |
| DOMPurify 白名单限制 | 仅允许 strong/em/a/br，最小化 XSS 面 |
| forgot-password 防枚举 | 无论邮箱是否存在返回相同消息 |
| Error Boundary 用 `onErrorCaptured` | Vue 3 Composition API 原生方式，无需第三方库 |
